# Hoot

Slices of the character sheet, one PNG per pose. Transparent background,
roughly square, 512px on the long edge is plenty — nothing shows Hoot larger
than 96pt.

    hoot_reading.png       holding an open book
    hoot_excited.png       wings up, books at their feet
    hoot_thinking.png      head tilted, question mark
    hoot_sleeping.png      asleep on a stack of books
    hoot_idea.png          wing raised, lightbulb
    hoot_celebrating.png   graduation cap, confetti
    hoot_avatar.png        head only, for a small round frame

Any file that is missing is drawn instead — see `lib/ui/widgets/hoot.dart`.
The app runs with this directory empty; adding a file is all it takes to
switch that pose over to the artwork.
